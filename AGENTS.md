# Notes for coding agents

- This is a hackathon web app built by a small, mostly non-technical team. Favor simple, working solutions over clever ones, and explain changes in plain English.
- Several agents work in parallel on separate branches. Stay inside the area your task describes and avoid broad refactors or renames that would conflict with other branches.
- Never push to `main` directly; open a pull request.
- Once the app exists, keep the "Run the app" section of README.md accurate.
